PREMIERE COMMAND DEFAULTS

Command behavior

frames
Stagger timing

Ascending starts with lower-numbered tracks; Descending starts with higher-numbered tracks.

Tokens: {sequence}, {index}, {clip}. Illegal filename characters are replaced.

Overlapping clips always merge. Only video and image clips are queued — adjustment layers, mattes and graphics are skipped.

Names are read as K1 Beige O1 → key K1, variant Beige, option 1. The key must always match exactly; the option is lenient. Stills are never swapped for video. A clip is only replaced when one file wins clearly — run the dry run first.
